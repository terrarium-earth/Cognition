v2.4.3-beta

[Changes]
- Big rework to Memory Tablet:
  - Memory Tablet can now be used to remotely access an Obelisk up to 48 blocks away
  - However, as a consequence of this change, there is now a one-to-one player-to-obelisk correspondence
  - This reverts the change in v2.4.2 -- Players can no longer link themselves to multiple Obelisks
  - Obelisks still retain player data if they are moved around
  - There is no change to experience recovery functionality
- Changed Memory Tablet recipe to require an enchanted book (any)
- Added config option to allow Enlightened Amulet to ignore orbs spawned by bookshelves (false by default)

[Bugfixes]
- (1.21.1) Fixed Enlightened Amulet spawning zero value orbs
- Removed unused files
